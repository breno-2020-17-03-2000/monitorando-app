Monitorando: Uma Plataforma Inovadora para Gestão de Mentorados

Trata-se de uma aplicação para gestão de mentorados. Essa aplicação denomina-se como "Monitorando", que se divide em várias partes e abas, desde o login, até a página
de agendamento de horários, tal plataforma usa como ferramentas de autenticação, algoritmos de PBKDF2, algoritmos de derivação de chaves, e assim por diante. 
Essa aplicação trabalha com tarefas do mentorado, a gravação de vídeos dentro da plataforma, então a pessoa pode gravar o vídeo dentro da plataforma para 
assistir depois. Dividida em nove abas, e desenvolvida na plataforma de design "Figma".
